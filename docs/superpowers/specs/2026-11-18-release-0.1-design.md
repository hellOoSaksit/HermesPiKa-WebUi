# Design: Release 0.1 with an easy installer (normal and Docker)

Status: approved by the person, 2026-11-18.

## Why
The person wants to use hpk on another machine. A beginner must be able to install it with no manual steps: download and double-click (or one command), and hpk installs Hermes Agent too when it is missing.

## Goals
1. **Normal install, Windows:** download `hpk.exe` and double-click it.
   - It installs itself for the current user into `<hpk data>/bin`, adds that folder to the user PATH, and adds a Start-menu shortcut.
   - It then opens HPK Console. The first-run screen (which already exists) finds Hermes, or offers to install the tested Hermes v0.23.1, and then adds hpk to Hermes.
2. **Normal install, any OS, one command:** `install.ps1` (Windows) and `install.sh` (macOS and Linux).
   - They pick the right release archive and verify it against `checksums.txt` (SHA-256).
   - They run `hpk self-install`, then start `hpk`.
3. **Docker:** one compose file using a prebuilt multi-arch image `ghcr.io/<owner>/hpk-hermes:<version>` (Hermes and hpk in one container). `docker compose up -d`, then open the Console. A helper command prints the one-time owner token.
4. **Release automation:** a tag `v0.1.0` produces a draft GitHub release.
   - Contents: all 6 archives, a bare `hpk.exe` for Windows amd64 (for double-click), `checksums.txt`, SBOMs, the two install scripts, and the Docker image.
   - A person publishes the draft.
5. **Version:** CHANGELOG `0.2.0 (unreleased)` becomes `0.1.0`.
6. **Docs:** a beginner install guide in English (`docs/install.md`, top section), linked to an identical Thai guide (`docs/install.th.md`): same sections, same steps, only the language differs. README's Install section is English and has a link "คู่มือภาษาไทย" to the Thai guide.

## Non-goals
- No signed installer or MSI. The unsigned exe shows SmartScreen the first time, and the guide shows "More info → Run anyway".
- No auto-update.
- No Homebrew, Scoop or winget yet.

## Decisions
- Self-install triggers when `hpk` runs with no arguments from a folder that is not `<hpk data>/bin`. It prints each step and needs no prompt, because double-click is the consent. `hpk self-install` and `hpk self-uninstall` are explicit commands.
- An older installed copy is replaced. A running hpk is stopped first (`hpk stop`).
- PATH:
  - Windows: `HKCU\Environment\Path`, then broadcast `WM_SETTINGCHANGE`.
  - macOS and Linux: append one marked line to the shell profile files that exist (`~/.profile`, `~/.zshrc`, `~/.bashrc`).
- Install scripts download only from the project's GitHub releases. They refuse to continue on a checksum mismatch.
- The Docker image is the existing `docker/hermes` image, built for amd64 and arm64 in the release workflow and pushed to GHCR. The guide notes that the package may need its visibility set to public once.
