เปิด HPK Console จากทางลัดก่อน

hpk เปิดอยู่ แต่เบราว์เซอร์นี้ยังไม่ได้รับอนุญาต ให้เปิด "HPK Console" จากเมนูสตาร์ต ทางลัดจะเปิด hpk ให้ถ้ายังไม่เปิด แล้วอนุญาตเบราว์เซอร์นี้ไว้ 30 วัน

ลองอีกครั้ง

Open HPK Console from its shortcut first

hpk is running, but this browser has not been let in yet. Open "HPK Console" from the Start menu: it starts hpk if needed and lets this browser in for 30 days.
